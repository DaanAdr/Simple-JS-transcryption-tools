Substitution Ciphers

Monoalphabetic Substitution Ciphers

  • Atbash Cipher -- Transcode Atbash Cipher

    The Atbash cipher is a simple substitution cipher that replaces each letter of the plaintext character set with its counterpart on the other end of the character set.

    Assuming the alphabet is used, in this cipher:

    • 'A' is replaced by 'Z'
    • 'B' is replaced by 'Y'
    • 'C' is replaced by 'X'
    • ...
    • and so on, until 'Z' is replaced by 'A.'



  • A1Z26/Number-to-Letter Cipher -- Transcode A1Z16 Cipher

    In this cipher, each character of the plaintext character set is replaced by an incrementing number. Usually the alphabet is used, with the ciphertext character set being each letter's position in the alphabet

    • A = 1
    • B = 2
    • ...
    • Z = 26



    • Added Alphabetical Rank A1Z26 Cipher -- Transcode Added Alphabetical Rank A1Z26 Cipher

      Substituting the characters for this cipher works in much the same way as the A1Z26 cipher, though there is one difference. Rather than just displaying the numerical value for each letter, it add the numerical value for a letter to the numerical value for the previous letters

      For example, the text "ABC", will be displayed as: "1 4 9"

      • A = 1
      • C = 3 + the previous value 1 = 4
      • E = 5 + the previous value 4 = 9



  • Shift Cipher -- Transcode Shift Cipher

    A shift cipher, also known as a Caesar cipher, is a type of substitution cipher where each letter in the plaintext is 'shifted' a certain number of places down or up the plaintext character set. The shift value is a number that determines how many positions each letter is moved.

    For example, with a shift of 3:

    • A becomes D
    • B becomes E
    • ...
    • Y becomes B
    • Z becomes C



  • Keyword Cipher -- Transcode Keyword Cipher

    A keyword cipher is a type of substitution cipher that uses a keyword to create a unique character set for encoding and decoding messages. In this cipher, the keyword is written down and letters from the keyword are used to form the beginning of the ciphertext character set. Any remaining letters of the plaintext character set that are not in the keyword are then used to fill out the rest of the ciphertext character set.

    For example, if the plaintext character set is the alphabet and the keyword is "CIPHER", the ciphertext character set would start with:

    C I P H E R

    Followed by the letters:

    A B D F G J K L M N O Q S T U V W X Y Z

    Forming the complete ciphertext character set:

    C I P H E R A B D F G J K L M N O Q S T U V W X Y Z

    To encode a message, you would look at the position of the character in the plaintext character set, and then replace it the character that is in the same position in the ciphertext character set. To decode, you would do the reverse.

    Ofcourse, you can also place the keyword at the end of the remaining letters in the alphabet. This would then become a reverse keyword cipher.




  • Affine Cipher -- Transcode Affine Cipher

    The affine cipher is a type of monoalphabetic substitution cipher, where each character in a character set is mapped to its numeric equivalent, encrypted using a mathematical equation, and then converted back to a letter. The encryption function for the affine cipher can be expressed as:

    E = (A * X + B) mod L

    • X refers to the position of the character in the alphabet
    • A is a coprime of that length of the character set
    • B is in the range between 0 and the length of the character set
    • E is the position of the encrypted character in the character set
    • L is the length of the character set

    Decrypting an affine ciphertext can be done as follows (If you don't want to create a ciphertext character set):

    ((L - A) * (Y - B)) mod L

    • Y refers to the position of the ciphercharacter in the alphabet

Polyalphabetic Substitution Ciphers

  • Vigenere & Tritermius Cipher -- Transcode Vigenere Cipher

    The Vigenère cipher is a method of encrypting alphabetic text by using a simple form of polyalphabetic substitution. It employs a keyword, where each letter of the keyword corresponds to a shift in the alphabet for the plaintext letters.

    The Vigenère cipher is more secure than a simple Caesar cipher because it uses multiple Caesar ciphers based on the letters of the keyword, making it harder to break without knowing the keyword. However, it can still be vulnerable to certain types of cryptanalysis, especially if the keyword is short or predictable.

    If you use the alphabet as keyword, you're essentially using the Tritermius cipher.




  • Beaufort Cipher -- Transcode Beaufort Cipher

    The Beaufort cipher is a polyalphabetic substitution cipher that is similar to the Vigenère cipher. It uses a keyword to encrypt and decrypt messages, but it uses a different calculation to determine the shited character.




  • Autokey/Autoclave Cipher -- Transcode Autokey/Autoclave Cipher

    The Autokey cipher is a polyalphabetic substitution cipher that is similar to the Vigenère cipher. It uses a keyword to encrypt and decrypt messages, but instead of repeating the keyword to create a keystream, it appends to message to the end of the key, in order to create the keystream.
